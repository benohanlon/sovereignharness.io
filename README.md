# sovereignharness.io

Small public landing page for Sovereign Harness, hosted by GitHub Pages from the main branch root. This website repository is separate from the private OODA and personal harness sources.

The primary button opens the reader’s native email preferences, where they explicitly switch on Sovereign Harness. New readers first use the linked native publication signup form, then choose the Section. The public Section page is linked separately. Both automatic section enrolment options were disabled at creation: no existing list copied and no automatic addition of general-publication subscribers. Publication membership and Section email preferences are managed on Substack. The website does not store email addresses or operate its own mailing service. Signing up is not a confirmed alpha-cohort place.

Edit index.html and style.css, review desktop/mobile layouts and links, then commit to main to deploy. CNAME binds sovereignharness.io; keep it when updating the page. GitHub Pages handles HTTPS.

The local fonts are unmodified OFL fonts; their licences are bundled in assets. The eye artwork is an AI-generated project asset. Its inclusion here does not publish the private harness or confer official Nous Research / Hermes branding.

Open Graph and large-image social-card metadata point to assets/eye.jpg, the clean, text-free 1774 × 887 eye requested for WhatsApp and Signal sharing. The earlier typographic banner and its editable SVG remain as previous artwork, not the active link preview. Individual services may cache their previews. The responsive page hero remains accessible HTML text over the clean eye artwork.
