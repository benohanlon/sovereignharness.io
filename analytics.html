Website analytics

Ben O’Hanlon uses PostHog EU to count page loads and selected actions so he can see which parts of the site people use. Events include the page address without query strings or fragments, the action and a random ID that resets on each page load.

Analytics use no cookies, record no sessions and send no prompt text or clipboard contents. PostHog receives the event requests and is configured to anonymise IP addresses.

We store your opt-out choice in this browser. If you use another browser or clear this site’s data, set the preference again. The site also respects Global Privacy Control and Do Not Track signals when your browser supplies them.
